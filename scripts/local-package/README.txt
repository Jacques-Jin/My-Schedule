我的日程 · 本地版（v62）
========================

【使用方法】
双击「启动本地版.bat」，浏览器会自动打开 http://127.0.0.1:8100/
停止服务：双击「stop-local.bat」，或关闭最小化的服务器窗口。

【改开屏文字（整活专用）】
双击「开屏文字编辑.bat」，浏览器打开 http://127.0.0.1:5399/
改主/副标题 → 保存 → 刷新 http://127.0.0.1:8100/ 立即生效（无需重启）。
「重置为默认」恢复「我的日程 / My Schedule」。
文字存在本文件夹的 app\splash-text.json，随文件夹一起拷贝/发送，
同学电脑上看到的就是你改过的版本。

【这是什么】
完全离线运行的独立版本：内置 Deno 运行时 + 前端构建产物 + 本地 API 服务器，
不需要安装 Node.js、npm 或任何开发环境，整个文件夹拷到任何 Windows
电脑上都能直接双击运行（也可以整个文件夹发给别人）。

【数据说明（重要）】
- 本版本的数据保存在「当前浏览器」的 IndexedDB 中（源：127.0.0.1:8100）。
- 不与线上网站（my-schedule-akzzfsdx3vh.qoder.zone）同步。
- 不与安卓 APP 同步。
- 换浏览器、换电脑、或用无痕模式打开，数据不会跟随。
- 服务器每次启动会重置为内置种子数据，但浏览器 IndexedDB 中的
  个人数据不受影响（应用以 IndexedDB 为准）。

【目录结构】
app\        前端构建产物（v63，含 splash-text.json 开屏文字）
server\     本地 API 服务器 + 开屏文字编辑器（Deno 脚本）
deno\       内置 Deno 运行时
启动本地版.bat / stop-local.bat  启动与停止
开屏文字编辑.bat                 开屏文字编辑器（端口 5399）

【与开发版的区别】
开发版（项目根目录的 启动.bat）需要 Node + Deno 环境、跑 Vite 热更新，
端口 5173/8000；本地版是单端口 8100 的成品，两者数据互不相通
（IndexedDB 按来源隔离），可并存运行。
