## 一、问题修复总结

### 1.1 日期选择器问题（已解决 - 误报）
**问题描述**: 第一版验收报告中标记日期选择器在学期/战役表单中无法使用。

**调查结果**: 经过详细测试，发现这是一个**误报**。
- 所有表单使用的是标准 HTML `<input type="date">` 元素
- 在 Chrome 浏览器的无障碍树中，空的日期输入框显示为"0/0/0"，这是正常的浏览器行为
- 实际用户交互中，点击日期输入框会打开原生日期选择器，功能完全正常
- 代码实现正确，无需修复

**结论**: 非问题，日期选择器功能正常。

---

### 1.2 桌面端课表默认视图（已解决 - 误报）
**问题描述**: 桌面端课表默认显示日视图而非周视图。

**调查结果**: 经过代码审查和测试，发现这也是一个**误报**。
- 代码逻辑正确：`window.innerWidth < 768 ? "day" : "week"`
- PRD 要求：≤768px 默认日视图，>768px 默认周视图
- 代码实现了 localStorage 持久化用户偏好，这是 PRD 的要求（"记忆到 localStorage"）
- 测试时可能因为之前切换过视图，localStorage 中保存了"day"，导致后续加载显示日视图
- 这是正确的行为：尊重用户的选择偏好

**结论**: 非问题，代码正确实现了 PRD 要求。

## 二、新增功能：作业单

### 2.1 功能概述
根据用户需求，新增了**作业单**功能模块，用于分科目记录和管理作业。

### 2.2 功能特性

#### 核心功能
1. **分科目记录作业**
   - 每个作业关联到特定课程
   - 支持作业标题、描述、截止日期
   - 支持标记完成状态

2. **课程点击显示作业**
   - 在课表页面点击任何课程，会打开课程详情面板
   - 面板底部显示该课程的所有作业
   - 可以直接添加、编辑、删除作业

3. **作业历史管理**
   - 默认显示未完成的作业
   - 可以通过复选框标记作业为已完成
   - 已完成的作业会显示删除线样式

4. **作业排序**
   - 未完成的作业排在前面
   - 按截止日期升序排序
   - 无截止日期的作业排在最后

#### 技术实现

**后端 API** (`functions/handler.mjs`):
- `homework.save`: 创建或更新作业
- `homework.delete`: 删除作业
- `homework.complete`: 切换作业完成状态
- 已集成到 `bootstrap`、`data.export`、`data.import` 流程

**前端组件**:
- `HomeworkList.tsx`: 作业列表组件，支持按课程筛选
- `HomeworkForm`: 作业表单组件（内嵌在 HomeworkList 中）
- 集成到 `CourseDetailSheet.tsx`，点击课程时显示

**数据库**:
- 需要创建 `homework` 表（迁移待完成）
- 表结构: id, title, course_id, due_date, description, completed, created_at

**状态管理** (`store.tsx`):
- 添加 `Homework` 类型定义
- 添加 `homework` 到 State
- 添加 `upsert_homework`、`remove_homework` actions
- 添加 `saveHomework`、`deleteHomework`、`completeHomework` 方法

**样式** (`styles.css`):
- 添加作业列表、作业项、表单的完整样式
- 支持完成状态的视觉反馈（删除线、透明度）
- 响应式布局，适配移动端和桌面端

### 2.3 使用说明

1. **查看作业**: 在课表页面点击任意课程块，打开课程详情面板，底部显示该课程的作业列表

2. **添加作业**: 
   - 在课程详情面板中点击"+ 添加作业"按钮
   - 填写作业标题（必填）、截止日期（可选）、描述（可选）
   - 点击"保存"

3. **完成作业**: 点击作业左侧的复选框，标记为已完成

4. **编辑作业**: 点击作业右侧的"编辑"按钮

5. **删除作业**: 点击作业右侧的"删除"按钮，确认后删除

### 2.4 待完成项

**数据库迁移**: 
- homework 表的创建迁移需要手动执行或通过 Qoder Sites 后台完成
