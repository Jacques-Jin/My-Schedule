### 2. 主题选择显示 Bug 修复
**问题**：选择 Dark Glass 主题后，再次进入设置→外观，显示 Liquid Glass 为选中状态。

**根因**：
- `AppearanceSection` 从 `state.settings.theme`（服务器状态）读取当前主题
- 服务器 settings 表无 theme 列（平台不支持 ALTER TABLE）
- 每次 bootstrap 时 theme 被重置为 "default"

**修复方案**：
- `AppearanceSection` 改为从 localStorage 读取当前主题（`getStoredTheme()`）
- `App.tsx` 启动时也使用 `getStoredTheme()` 而非 `state.settings.theme`
- `settings.save` handler 增加 theme 字段（若服务器支持则持久化）
- bootstrap 查询增加 theme 列
- `AppearanceSection` 的 saveSettings 调用增加 try-catch（服务器不支持时静默失败）

**修改文件**：
- `src/pages/SettingsPage.tsx` — AppearanceSection 改用 localStorage
- `src/App.tsx` — 启动主题恢复改用 localStorage
- `functions/handler.mjs` — settings.save 和 bootstrap 增加 theme 字段
