# 开发日志 · Runtime v61

**日期**：2026-10-02
**范围**：仅网页端（本轮按用户要求不做 APK 操作）
**主题**：弹窗可读性提升 + 开屏扫光放慢

## 背景

开屏动画「光迹 · Trace」在 v60 定稿后，用户手动验收提出两项 UI 调整：

1. 新建日程等弹窗（Sheet）背景信息干扰输入，希望弹窗不透明度略微提高。
2. （原计划）APP 端隐藏状态栏、系统导航条配色适配——**本轮用户改为先不动 APK**，仅做开屏与弹窗调整。

随后用户又对开屏提出：文字排列完毕后「我的日程」由左至右的背景闪亮（玻璃扫光）过程过于短暂，希望放慢。

## 变更 1：弹窗遮罩与面板不透明度

半透明的两套主题背景透出过多，干扰表单阅读与输入。提高遮罩压暗与面板实度：

| 位置 | 旧 | 新 |
| --- | --- | --- |
| 默认 `.sheet-overlay` 背景 | `rgba(0,0,0,0.2)` | `rgba(0,0,0,0.32)` |
| 默认 `.sheet-panel` 背景 | `rgba(255,255,255,0.78)` | `rgba(255,255,255,0.88)` |
| dark-glass `.sheet-panel` 背景 | `rgba(22,22,32,0.82)` | `rgba(22,22,32,0.88)` |

Neo-Brutalism 与 Paper Terminal 的面板本就是实色，无需改动。
注意：运行时主题 CSS 由 `public/themes/*.css` 提供（`src/themes/*.css` 未被 import），
故 dark-glass 的两个副本同步修改以保持一致。

## 变更 2：开屏玻璃扫光放慢

`.splash-title::after` 的高光扫过（`splash-glass-sweep`）时长由 **0.45s → 1s**。

扫光在 highlight 阶段进入时启动，选择器组覆盖 highlight/poise/closing，
动画以 `forwards` 持续、不因阶段切换重启；1s 时长在桌面（highlight 2200ms 起，
poise 至 3600ms）与移动（1900ms 起，poise 至 3100ms）时间轴内均能完整播完，
收尾淡出前高光已自然移出画面。

## 变更文件
