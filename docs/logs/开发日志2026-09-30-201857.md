## 1. 问题背景（用户反馈）

1. 各按钮呈现"诡异的灰色"；要求**不通过增加白色占比**的方式提升按钮亮度与对比度；
2. 今日时间线完全半透明，内容不可读（bug）；
3. 周课表视图的时间区块呈灰色，不美观；应默认深色（不高亮），**鼠标悬停时才高亮**。

## 2. 根因分析

| # | 现象 | 根因 |
|---|------|------|
| 1 | 按钮灰感 | 深色主题下中性按钮沿用低饱和白灰 tint（`rgba(255,255,255,0.04~0.08)` 与半透明 `--glass-bg`），在暗底上呈无彩色灰块 |
| 2 | 时间线过透 | `styles.css` 的 `.timeline-item.past { opacity: 0.45 }` 叠加 v33 中降至 0.45 alpha 的 `--glass-bg`，已过时条目实际不透明度仅约 0.2 |
| 3 | 周课表灰块 | `styles.css` 的 `.wg-cell { background: rgba(255,255,255,0.35) }`（浅色主题格子底）未在深色主题覆盖，白 35% 叠暗底 = 中灰块 |

## 3. 修复方案（仅改动 `src/themes/dark-glass.css`）

### 3.1 彩色玻璃按钮：以饱和度提亮，而非加白

中性按钮统一改为**靛蓝渐变 tint + 发光描边**，亮度来自色相饱和度：

```css
background: linear-gradient(180deg, rgba(139,156,240,0.30), rgba(104,92,224,0.16));
border-color: rgba(139,156,240,0.45);
color: #d9e0ff;
box-shadow: var(--glass-highlight), 0 1px 8px rgba(139,156,240,0.28);
```

覆盖范围：`.tb-btn / .filter-chip / .day-chip / .ws-btn / .ws-semester-select /
.batch-btn / .tf-btn / .cf-wd-btn / .tf-wd-btn / .tf-week-btn / .day-mark-btn /
.campaign-tool-btn / .do-kind-btn`（均带 `:not(.active)` 保护选中态）。

选中态改为**高亮靛蓝实心**，与深色轨道形成强对比：

```css
background: linear-gradient(180deg, #96a5f5, #6d7fe0);
box-shadow: var(--glass-highlight), 0 2px 10px rgba(139,156,240,0.5);
```

切换轨道（`.nav-tabs / .view-toggle / .settings-tabs / .tasks-tabs`）改为深色底衬
`rgba(10,10,20,0.55)`，凸显选中 pill。

### 3.2 时间线可读性

```css
[data-theme="dark-glass"] .timeline-item { background: rgba(20,20,36,0.82); }
[data-theme="dark-glass"] .timeline-item.past { opacity: 0.78; }   /* 原 0.45 */
[data-theme="dark-glass"] .home-todo-item,
[data-theme="dark-glass"] .task-item { background: rgba(20,20,36,0.82); }
```

同时 `--glass-bg` 令牌回调至 `rgba(21,21,36,0.72)`（v33 的 0.45 过透），
卡片整体恢复可读不透明度，环境光晕仍经 blur 折射可见。

### 3.3 周课表：默认深色、悬停高亮

```css
[data-theme="dark-glass"] .wg-cell        { background: rgba(8,8,16,0.45); }
[data-theme="dark-glass"] .wg-cell:hover  { background: rgba(139,156,240,0.25); }
[data-theme="dark-glass"] .wg-cell.holiday-cell       { background: rgba(255,69,58,0.08); }
[data-theme="dark-glass"] .wg-cell.holiday-cell:hover { background: rgba(255,69,58,0.18); }
[data-theme="dark-glass"] .wg-cell.drag-over          { background: rgba(139,156,240,0.32); }
```

另补齐 `.rb-label / .rb-day` 的深色覆盖（例行带格子此前残留浅色白底）。
