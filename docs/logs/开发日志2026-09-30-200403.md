---

## 1. 问题背景（用户反馈）

1. 深色背景过黑，影响文字信息获取；
2. 希望背景加入紫色、蓝色、粉色等**高亮度图形**，以呈现液态玻璃的半透明质感；
3. 灰色文字在黑色背景下难以看清，要求修正所有灰色文字的 UI 显示。

## 2. 根因分析

### 2.1 标题/继承文字呈近黑色（关键 Bug）

`src/globals.css`（shadcn/Tailwind 基础样式）中存在：

```css
body {
  background: var(--background);
  color: var(--foreground);   /* #171717 */
}
```

由于 Vite 开发模式下 `globals.css` 的 `@import "tailwindcss"` 异步解析，
其 `<style>` 标签注入顺序晚于 `styles.css`，导致同优先级的 `body` 规则中
**globals.css 胜出**。于是所有未显式设置颜色、仅继承 body 颜色的文字
（页面标题 h2、分区标题 h3 等）在深色主题下渲染为 `#171717`（近黑），
在深色背景上几乎不可见。

浏览器实测（修复前）：

```
h2 color  = rgb(23, 23, 23)   ← 近黑，不可读
--color-text（变量本身） = #f5f5f7  ← 变量正常，但被 body 字色规则绕过
```

### 2.2 背景过黑

原环境光晕透明度仅 0.12–0.20，基色 `#0a0a10` 接近纯黑，
毛玻璃的半透明质感无从体现。

### 2.3 次要文字偏暗

`--color-text-secondary: #8e8e93` 在深底上对比度不足。

## 3. 修复方案（仅改动 `src/themes/dark-glass.css`）

### 3.1 高优先级 body 覆盖（修复继承文字）

```css
[data-theme="dark-glass"] body {
  background-color: var(--color-bg);
  color: var(--color-text);
}
```

选择器优先级 (0,1,1) 高于 globals.css 的 `body` (0,0,1)，
与注入顺序无关，稳定生效。修复后实测 h2/body 颜色 = `rgb(245, 245, 247)`。

### 3.2 高亮度环境光晕（紫/蓝/粉）

```css
background-color: #12121f;
background-image:
  radial-gradient(ellipse 75% 55% at 12% 16%, rgba(147, 102, 255, 0.50) 0%, transparent 62%),  /* 紫 */
  radial-gradient(ellipse 65% 50% at 88% 20%, rgba(64, 132, 255, 0.45) 0%, transparent 58%),   /* 蓝 */
  radial-gradient(ellipse 70% 60% at 50% 90%, rgba(255, 82, 176, 0.35) 0%, transparent 58%),   /* 粉 */
  radial-gradient(ellipse 55% 45% at 78% 60%, rgba(96, 165, 250, 0.32) 0%, transparent 52%),   /* 亮蓝 */
  radial-gradient(ellipse 45% 40% at 22% 68%, rgba(192, 132, 252, 0.34) 0%, transparent 52%);  /* 亮紫 */
```

光晕透明度由 0.12–0.20 提升至 0.32–0.50，共 5 团高亮度色块，
透过 `backdrop-filter: blur() saturate()` 形成明显的液态玻璃折射感。

### 3.3 文字与玻璃令牌提亮

| 令牌 | 旧值 | 新值 | 说明 |
|------|------|------|------|
| `--color-text-secondary` | `#8e8e93` | `#b4b4c4` | 次要文字提亮，深底可读 |
| `--color-bg` | `#0a0a10` | `#10101c` | 基色提亮，脱离纯黑 |
| `--glass-bg` | `rgba(28,28,38,0.55)` | `rgba(32,32,50,0.45)` | 更透，让光晕透出 |
| `--glass-border` | `rgba(255,255,255,0.10)` | `rgba(255,255,255,0.14)` | 边缘更清晰 |
| `--glass-highlight` | `…0.08` | `…0.12` | 顶部高光增强 |
| `--color-primary` | `#7B8CDE` | `#8B9CF0` | 主色提亮（16 处 rgba 同步更新） |
| 占位符文字 | `rgba(255,255,255,0.25)` | `rgba(255,255,255,0.40)` | 输入框占位符可读 |

## 4. 验证结果
