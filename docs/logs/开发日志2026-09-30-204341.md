## 1. 本次完成的工作

### 1.1 功能概述
新增第三套完整主题 **Neo-Brutalism（新粗野主义）**，灵感来自 Gumroad、Figma 社区、Framer 的视觉语言。与 Liquid Glass / Dark Glass 的柔和玻璃质感完全相反，本主题追求「大胆、直白、有态度」的海报式表达。

### 1.2 设计原则对照

| # | 用户要求 | 实现方式 |
|---|----------|----------|
| 1 | 流畅度第一 + 打击感 | 80–120ms 线性过渡；按钮按压时 `translate(4px,4px)` + 阴影归零，产生「按下贴纸」的打击反馈 |
| 2 | 粗体无衬线字体 | 引入 Google Fonts `Space Grotesk`（400–900 全字重）；标题 800/900 加粗 + 大写 + 负字距 |
| 3 | 硬边缘零圆角 | 全部 `--radius*` 令牌设为 `2px`；卡片/按钮/输入框 `border-radius: 0` |
| 4 | 高饱和撞色 | 亮黄 `#ffe600`、电光蓝 `#0055ff`、荧光粉 `#ff3399`、薄荷绿 `#00ffaa`、橙 `#ff6600`、紫 `#9933ff`，搭配大面积黑白 |
| 5 | 粗实线边框 + 硬偏移阴影 | 所有交互元素 `3px solid #000` + `box-shadow: 4px 4px 0 #000`；无渐变、无模糊 |
| 6 | 干脆动效 | `transition: all 80ms linear`（无缓动曲线）；按压=阴影归零+位移；hover=边框/底色切换 |
| 7 | 纯色块/网格背景 | body 使用 `#fffef5` 底色 + 24px 双向网格线（`linear-gradient` 1px 线） |
| 8 | 海报氛围 | 大写标题 + 粗黑下划线、黑色导航条 + 黄色高亮、撞色区块 |

### 1.4 设计令牌（Design Tokens）

```css
[data-theme="neo-brutalism"] {
  /* 表面 — 平坦不透明，无玻璃 */
  --glass-bg: #ffffff;
  --glass-border: #000000;
  --glass-blur: 0px;
  --glass-shadow: 4px 4px 0 #000000;
  --glass-highlight: none;

  /* 撞色 */
  --color-primary: #0055ff;      /* 电光蓝 */
  --nb-yellow: #ffe600;          /* 亮黄 */
  --nb-pink:   #ff3399;          /* 荧光粉 */
  --nb-mint:   #00ffaa;          /* 薄荷绿 */
  --nb-orange: #ff6600;
  --nb-purple: #9933ff;

  /* 硬边缘 */
  --radius: 2px; --radius-sm: 2px; --radius-lg: 2px;
  --radius-xl: 2px; --radius-pill: 2px;

  /* 硬阴影 */
  --shadow-sm: 2px 2px 0 #000;
  --shadow-md: 4px 4px 0 #000;
  --shadow-lg: 6px 6px 0 #000;

  /* 干脆动效 */
  --ease: linear; --ease-spring: linear;
  --dur-fast: 80ms; --dur: 100ms; --dur-slow: 120ms;
}
```

### 1.5 关键样式特征

- **全局去玻璃化**：`[data-theme="neo-brutalism"] * { backdrop-filter: none !important; }` 一次性清除所有毛玻璃。
- **导航条**：桌面顶部 / 移动底部均为亮黄底 + 3px 黑边；活动标签反白或反黄。
- **按钮打击感**：默认 `box-shadow: 3px 3px 0 #000`；`:active` 时 `transform: translate(3px,3px)` + `box-shadow: 0 0 0 #000`，模拟物理按压到底。
- **周课表**：网格 `gap: 2px` + 黑底形成粗黑分隔线；普通日=黄、今天=薄荷绿、节假日=荧光粉。
- **焦点卡**：紫色实底 + 白字 + 6px 硬阴影，作为首页视觉锚点。
- **滚动条**：黑色方块滑块 + 黑边轨道，延续粗野质感。
