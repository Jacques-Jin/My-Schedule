# 开发日志 2026-10-02 21:30 — v57 开屏退场与调度修复

## 背景
v56 开屏动画上线后收到三轮真机反馈：退场时主体图标（圆环）瞬间消失、以及手机端「我的日程」字样根本不出现。

## 问题定位
1. **圆环退场瞬消失**：`src/splash.css` 中 `.splash-arc` 基态为 `stroke-dashoffset: 339.292`（完全隐藏），绘制/补合动画的选择器组不含 `exiting` 相位；进入退场相位时动画被移除，圆弧立即回到隐藏基态，而根背景仍在 0.6s 淡出 → 视觉上圆环" pop "出去。
2. **手机端字样不出现 / 开屏被提前掐断**：
   - 相位调度 effect 的依赖数组为 `[timing, onFinished, ready]`，而 `onFinished` 是 App 内联箭头函数，App 每次重渲染都会清空并重排全部相位定时器，时间轴被打乱。
   - 跳过逻辑监听 `pointerdown`/`keydown`，Android WebView 启动瞬间会投递一个杂散 pointerdown，在 poise 之前就触发 skip，开屏在字样揭示前被终止。

## 修改
- `src/splash.css`：新增 `.splash-phase-exiting .splash-arc { animation: none !important; stroke-dashoffset: 0 !important; }`，退场期间保持完整圆环，随根透明度一同淡出；`splash-text-exit` 时长 0.45s → 0.6s，与根淡出同步。
- `src/components/SplashScreen.tsx`：
  - 调度 effect 改为挂载时执行一次（依赖 `[]`），`ready` 与 `onFinished` 经 ref 读取，杜绝重渲染重排定时器。
  - 新增 `allowSkipRef`，poise 相位到达后才允许 tap/键跳过，屏蔽启动杂散输入。
