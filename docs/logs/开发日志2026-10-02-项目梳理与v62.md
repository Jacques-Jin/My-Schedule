## 二、本次新增：开屏文字可配置 + 本地编辑小工具

### 需求

用户希望「启动一个小小程序，直接更改网页端开屏动画的显示文字」，并提供「重置为默认」。

### 实现

1. **配置源**：新增 `src/splash-text.json`，形如 `{ "title": "我的日程", "subtitle": "My Schedule" }`。
2. **读取**：`src/components/SplashScreen.tsx` 以 `import splashText from "../splash-text.json"` 引入（tsconfig 已开 `resolveJsonModule`），渲染时 `splashText.title || "我的日程"`、`splashText.subtitle || "My Schedule"` 兜底，配置缺失/损坏也不会白屏。
3. **编辑工具**：新增 `scripts/splash-text-editor.mjs` —— 零依赖 Node 本地服务（端口 **5299**，避开 5173/5199/8000），提供一个 UTF-8 表单页：
   - 「保存」→ 以 UTF-8 写回 `src/splash-text.json`；
   - 「重置为默认」→ 恢复 `我的日程 / My Schedule`；
   - 启动后自动打开浏览器（win32）。
4. **启动器**：新增 `set-splash-text.bat`（ASCII 命名，避免 CMD 乱码），设置 Node 路径并拉起编辑服务。

### 生效方式

- **开发**：改完刷新 Vite dev server 即可看到新开屏文字（JSON 变更触发重载）。
- **线上 / APK**：需重新 `npm run build`（+ 部署 / 打包）后生效，因为文字在构建期被打包进产物。

### 验证

- `tsc --noEmit` 通过、`vite build` 通过。
- 本地起服务后用浏览器实测：中文标题「浏览器测试标题」保存后文件为正确 UTF-8；点「重置为默认」恢复 `我的日程 / My Schedule`。
- 端口曾与遗留进程 5199 冲突（EADDRINUSE），改为 5299 解决。

## 三、开屏动画「光迹 · Trace」最终定稿（v56–v62 汇总）

### 阶段状态机

`entering → drawing → settling → highlight → poise → closing → done`

- **entering**：安静空白拍（仅环境背景），动画缓入。
- **drawing**：圆环自 12 点顺时针画至 300°（留 60° 缺口），末端光点跟随。
- **settling**：容器弹簧脉冲 + 字标自下而上淡入 + 字距 0.35em→0.02em 收拢 + 副标题淡入。
- **highlight**：一道玻璃高光自左向右扫过标题（v61 起时长 1s，从容不 flash）。
- **poise**：凝定帧——圆环缺口仍开、文字完全显示且字距到位，刻意停留供识别品牌。
- **closing**（v60 合并）：补环 + 整页淡出 + 文字上浮**同时**进行（0.6s），圆环画完即页面消失，收尾不拖沓。
- **done**：卸载。

### 时间轴（ms）

| 阶段 | 桌面 | 移动 |
| --- | --- | --- |
| entering | 700 | 600 |
| drawing | 1800 | 1550 |
| settling | 2200 | 1900 |
| highlight | 2600 | 2250 |
| poise | 3600 | 3100 |
| closing | poise 起 +650ms 完成 | 同左 |
| maxDuration | 5000 | 5000 |

### 关键修复史

- **v57**：修复退场瞬移（exiting 阶段环回弹）；调度器改为 mount-once + refs，避免 App 重渲染重置计时；poise 前忽略杂散 pointerdown/keydown 防误跳过。
- **v58**：修复深色主题开屏文字不可见——主题 CSS 改为 boot 期注入 + splash 自带主题 token（`[data-theme="x"].splash-root`）。
- **v59**：增加「动画被抑制」降级（plain opacity/stroke-dashoffset 兜底），保证 WebView 关动画时内容仍可见。
- **v60**：修复淡出前字距回弹（forwards 填充离开选择器组所致）；合并补环+淡出为 closing；延长 poise。
- **v61**：扫光 0.45s→1s。
- **v62**：文字可配置。

## 四、主题系统

- 注册表 `src/themes/registry.ts`；加载器 `src/themes/loader.ts`（运行时注入 `/themes/*.css`，服务自 `public/themes/`）。
- `index.html` boot 脚本在首帧前设置 `html[data-theme]` 并注入对应主题 link，避免冷启动 token 空窗。
- 四套主题：
  - **Liquid Glass（默认）**：macOS 液态玻璃，浅色。
  - **Dark Glass**：深色液态玻璃 + 高级色系。
  - **Neo-Brutalism**：新粗野主义，实色硬边。
  - **Paper Terminal**：纸面终端点阵仪器风（DotGothic16 无简体字形，标题回退 monospace）。
- v61 起弹窗（Sheet）不透明度提高：默认遮罩 0.32 / 面板 0.88；Dark Glass 面板 0.88，减少背景干扰。

## 六、安卓 App（Capacitor 8）

- 内置模式：Web 资源打包进 APK；`capacitor.config.ts` 配置 appId/webDir/插件。
- 签名 release：`android/app/build/outputs/apk/release/app-release.apk`（~15MB）。
- 一键打包：`scripts/build-android.bat` / `.sh`；或手动 `npm run build` → `npx cap sync android` → `gradlew assembleRelease`。
- **系统条限制（重要）**：测试机（Android 15 / API35，OEM 皮肤）不允许应用改色/隐藏系统状态栏与导航条；edge-to-edge 与 `setNavigationBarColor` 均无效，`StatusBar.hide()` 仅藏图标留浅色空带。2026-10-02 尝试后已**回退到基线**，不再尝试。详见项目记忆 `android-rom-system-bars-limit`。
