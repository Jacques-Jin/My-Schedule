## 3. 数据同步 Toast 提示

### 功能描述
当数据同步到云端时，自动弹出提示：
- **数据同步中…** — 同步开始时（loading 状态）
- **数据同步成功** — 同步完成后
- **数据同步失败，将在恢复后重试** — API 调用失败时

### 技术实现

#### 文件变更
- `src/App.tsx` — 添加 `<Toaster theme="dark" position="top-center" />`
- `src/components/SyncIndicator.tsx` — 监听状态转换，调用 toast
- `src/styles.css` — sonner toast 深色玻璃主题样式

#### 核心逻辑
```typescript
useEffect(() => onSyncChange((s, p) => {
  const prev = prevStatus.current;
  
  if (s === "syncing" && prev !== "syncing" && p > 0) {
    toastId.current = toast.loading("数据同步中…");
  } else if (s === "synced" && prev === "syncing") {
    toast.success("数据同步成功", { id: toastId.current });
  } else if ((s === "offline" || s === "error") && prev === "syncing") {
    toast.error("数据同步失败，将在恢复后重试", { id: toastId.current });
  }
  
  prevStatus.current = s;
}), []);
```

#### 触发时机
仅在后台同步队列处理时弹出：
1. 用户修改数据 → 写入 IndexedDB → 尝试 API 调用
2. API 失败 → 入队到 `_sync_queue`
3. 2 秒后 `syncNow()` 处理队列 → 触发 toast

**不会**因每次操作都弹窗（避免打扰用户）。

#### 样式适配
```css
[data-sonner-toaster][data-theme="dark"] {
  --normal-bg: rgba(30, 30, 35, 0.85);
  --success-bg: rgba(22, 60, 36, 0.85);
  --error-bg: rgba(60, 20, 20, 0.85);
}
[data-sonner-toaster] [data-sonner-toast] {
  backdrop-filter: blur(20px) saturate(180%);
  border-radius: 12px;
  box-shadow: 0 4px 24px rgba(0, 0, 0, 0.3);
}
```

## 5. 架构决策

### 为什么用 sonner？
- 已安装在 `package.json` 但未使用
- 轻量级（~5KB）、无依赖
- 支持 toast 替换（loading→success/error）
- 暗色主题支持良好

### 为什么在 SyncIndicator 中触发 toast？
- 已监听 `onSyncChange`，无需额外订阅
- 状态转换逻辑集中，避免重复代码
- 与现有 SyncIndicator UI 共存（右上角胶囊 + 顶部 toast）

### 为什么用 toastId 替换而非堆叠？
- 避免用户看到多个 toast 堆叠
- loading→success/error 是同一事件的延续
- 更清晰的视觉反馈
