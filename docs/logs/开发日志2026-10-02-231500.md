# 开发日志 · Runtime v60

**日期**：2026-10-02
**范围**：仅网页端（本轮不重建 APK）
**主题**：开屏动画「光迹 · Trace」收尾节奏重构 + 字距回弹修复

## 背景

用户手动验收 v59 后确认文字已正常显示，效果满意，但提出两点问题：

1. 动画演示完毕、开屏页面淡出前，文字排列方式会短暂改变，像换了字体。
2. 开屏动画结束略显拖沓，希望把淡出提前——从「圆环未画完、文字完全显示且排列正确」那一帧开始淡出，到圆环画完时淡出彻底完成；同时略微延长那一帧的停留时间。

## 问题 1 定位：forwards 填充值在离开选择器组时回弹

标题的字距由 `splash-letter-spacing`（0.35em → 0.02em，`forwards`）驱动，且只在
`settling / highlight / poise / closing` 选择器组内生效。旧实现中淡出走的是独立的
`exiting` 阶段——一旦进入 `exiting`，标题脱离该选择器组，`forwards` 填充的字距失效并
回弹到基础的 0.35em，于是淡出前字距骤然变宽，看起来「像换了字体」。

**修复**：让收尾阶段 `closing` 保留在所有 reveal 选择器组内（draw-arc / spring-pulse /
text-reveal / letter-spacing / subtitle / glass-sweep），使标题在整个淡出过程中始终维持
终态字距，不再回弹。

## 问题 2 实现：合并「补环 + 淡出」为单一 closing 阶段

删除原先分离的 `holding` 与 `exiting` 阶段，收尾状态机简化为：
`entering → drawing → settling → highlight → poise → closing → done`。

`closing` 阶段（0.6s）内三件事同时发生：
- 根容器整体淡出（`splash-root-exit`）；
- 圆环缺口补齐为完整圆（`splash-close-gap`，56.549 → 0）；
- 文字上浮淡出、容器轻微放大（`splash-text-exit` / `splash-exit`）。

即：淡出从「圆环未画完、文字已完全显示且字距正确」的 poise 帧起步，与补环同步进行，
圆环画完时页面恰好彻底消失——收尾不再拖沓。

CSS 中 closing 专属规则排在 reveal 组之后，凭同特异性、后声明覆盖前者生效。

## 时间轴调整

| 阶段 | 桌面 | 移动 |
| --- | --- | --- |
| entering | 700 | 600 |
| drawing | 1800 | 1550 |
| settling | 2200 | 1900 |
| highlight | 2600 | 2250 |
| **poise（延长）** | **3600** | **3100** |
| closing | poise 起，+650ms 完成 | 同左 |

poise 帧停留时间由桌面 3200→3600、移动 2750→3100 延长，满足「略微增加那一帧显示时间」。
补环与淡出从 poise 帧起步，0.6s 内一体完成。

## 收尾门控

`closing` 只在 `ready` 为真或达到 `maxDuration`（5000ms）后触发，确保页面淡出时其下已有内容。
用户跳过（pointerdown/keydown，poise 后放行）同样进入 `closing` 而非瞬移消失。

## 降级与可达性

`prefers-reduced-motion` 下，reveal 组的 `!important` 关闭弧线/容器/文字运动，仅保留根容器
透明度淡出——收尾依旧平滑溶解，无缩放与上浮。
