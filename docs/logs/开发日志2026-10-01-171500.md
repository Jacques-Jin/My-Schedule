# 开发日志 2026-10-01 #6

## 安卓 App 打包 Phase 0–4：Capacitor 套壳 APK

### 概述

按 `docs/product/PRD-安卓App打包.md` 将现有 Web 应用打包为安卓 APK。采用 Capacitor 8 内置模式，Web 资源打包进 APK，后端复用线上边缘函数。

### Phase 0：环境与前置调研

- 安装 JDK 21（OpenJDK 21.0.2，华为镜像下载；Capacitor 8 实际要求 JDK 21，PRD 中 JDK 17 已过时）
- Android Studio + SDK 已就位（API 34/35、build-tools 35/36）
- CORS 探测：边缘函数已返回完整 CORS 头（`access-control-origin: *`），CapacitorHttp 为可选增强
- Gradle 镜像：腾讯镜像（Gradle 分发）+ 阿里云镜像（Maven 仓库），解决国内网络问题

### Phase 1：接入 Capacitor 基座

- 安装 `@capacitor/core`、`@capacitor/cli`、`@capacitor/android`
- 生成 `capacitor.config.ts`：appId `com.jack.myschedule`，webDir `dist`，CapacitorHttp 启用
- 添加安卓平台，生成 `android/` 工程
- `.gitignore` 新增 keystore、构建产物忽略规则

### Phase 2：Web 侧适配

| 文件 | 改动 |
|------|------|

### Phase 3：原生观感资源

- 用 `@capacitor/assets` 从 1024×1024 母版生成全套自适应图标（6 密度 mipmap + anydpi-v26）
- 生成启动屏资源（light/dark × portrait/landscape × 6 密度，共 87 个文件，9.39MB）
- 安装 `@capacitor/splash-screen`，配置 2s 展示时长、深色背景 `#0a0a0f`
- WebView 背景色设为 `#0a0a0f`，消除加载瞬间白闪
- `strings.xml` 应用名已为「我的日程」

### Phase 4：构建与打包

- 生成 release keystore（RSA 2048，有效期 10000 天）
- `keystore.properties` 配置签名（不入库，已在 .gitignore）
- `build.gradle` 添加 `signingConfigs.release`，release 构建自动签名
- Release APK 产出：**15MB**（低于 20MB 目标）
- 一键打包脚本：`scripts/build-android.bat`（CMD）+ `scripts/build-android.sh`（Bash）

### 字体子集化

Noto Sans SC 全量 TTF 各 11MB，使用 `pyftsubset` 子集化至 ~8900 字符（CJK 常用范围 U+4E00–U+6FFF + 全角 + 标点），每个文件降至 2.7MB，APK 从 34MB 降至 15MB。

### 关键决策

1. **JDK 21 而非 17**：Capacitor 8 的 `capacitor-android` 模块编译目标为 Java 21，JDK 17 无法构建
2. **CapacitorHttp 启用**：虽然后端已有 CORS 头，但启用原生 HTTP 桥更稳健
3. **字体 TTF 而非 woff2**：Capacitor 内置加载无需考虑网络传输体积，TTF 兼容性最广
