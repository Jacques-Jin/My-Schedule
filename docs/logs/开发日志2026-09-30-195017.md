## 1. 本次完成的工作

### 1.1 功能概述
在已有的 Liquid Glass 浅色主题基础上，新增 **Dark Glass 深色液态玻璃主题**。采用高级色系（Premium Color Palette）替换原有课程颜色，提升视觉质感。主题切换功能保持完整，用户可在设置中自由切换浅色/深色主题。

### 1.2 设计原则

| 优先级 | 原则 | 实现方式 |
|--------|------|----------|
| 1 | 深色沉浸感 | 深紫/蓝/青/酒红环境光晕 + 深色毛玻璃 |
| 2 | 高级色系 | 12 色 Premium Palette（蓝宝石/酒红/森林绿/琥珀金等） |
| 3 | 材质一致性 | 与浅色主题相同的 backdrop-filter 毛玻璃效果 |
| 4 | 可读性 | 高对比度文字（#f5f5f7）+ 适当的次要文字色（#8e8e93） |
| 5 | 主题切换 | CSS 自定义属性 + data-theme 属性切换 |

### 1.6 关键样式特征

- **环境背景**：4 色径向渐变（深紫/深蓝/深青/酒红），营造深邃空间感
- **毛玻璃卡片**：`backdrop-filter: blur(24px) saturate(180%)` + 深色半透明背景
- **光泽高光**：`inset 0 1px 0 rgba(255,255,255,0.08)` 顶部微妙高光
- **课程色块**：12 色高级色系，低饱和度+中等明度，深色背景下更优雅
- **主题切换**：点击设置中的主题卡片即可切换，无需刷新页面

## 2. 技术实现细节

### 2.1 主题加载机制

```typescript
// src/themes/loader.ts
let loadedThemeLink: HTMLLinkElement | null = null;

export function applyTheme(themeId: string) {
  const theme = THEMES.find(t => t.id === themeId);
  if (!theme) return;

  // 移除旧主题 CSS
  if (loadedThemeLink) {
    loadedThemeLink.remove();
    loadedThemeLink = null;
  }

  // 加载新主题 CSS（如果有）
  if (theme.cssFile) {
    const link = document.createElement("link");
    link.rel = "stylesheet";
    link.href = `/src/themes/${theme.cssFile}`;
    document.head.appendChild(link);
    loadedThemeLink = link;
  }

  // 设置 data-theme 属性
  document.documentElement.setAttribute("data-theme", themeId);
  localStorage.setItem("theme", themeId);
}
```

### 2.2 CSS 覆盖模式

深色主题采用 `[data-theme="dark-glass"]` 选择器覆盖浅色主题的 CSS 变量，而非复制全部样式：

```css
/* 浅色主题（默认） */
:root {
  --color-text: #1d1d1f;
  --glass-bg: rgba(255, 255, 255, 0.45);
}

/* 深色主题覆盖 */
[data-theme="dark-glass"] {
  --color-text: #f5f5f7;
  --glass-bg: rgba(28, 28, 38, 0.55);
}
```

### 2.3 共享色系模块

创建 `src/lib/colors.ts` 统一管理课程颜色，避免各组件重复定义：

