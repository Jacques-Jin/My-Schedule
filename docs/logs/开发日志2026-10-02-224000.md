# 开发日志 2026-10-02 22:40 — v59 开屏抗动画抑制加固

## 现象
v58 之后仍有环境（网页刷新）开屏文字不显示。

## 根因分析
开屏内容的可见性完全依赖 CSS 动画： 与  基态 ，仅靠 fade-in 动画变为可见；文字基态  仅靠 reveal 动画可见。任何抑制 CSS 动画的环境（浏览器效率模式/省电、特殊 WebView、动画开关）都会让内容永久停留在 opacity 0 —— 表现为"开屏只有背景、文字从头到尾不显示"。

- 圆环追加 plain  相位终态（drawing–poise 56.549，closing/holding 0），动画抑制时仍显示对应环态。
