## 遇到的问题

### 1. adb input tap 坐标映射
**现象**: WebView 按钮点击失效或误触  
**原因**: uiautomator bounds 与 adb tap 坐标不一致  
**影响**: 无法自动化测试编辑/删除操作  
**解决**: 标记为需手动验证

### 2. adb input text 中文支持
**现象**: `adb shell input text "中文"` 抛出 NPE  
**原因**: Android InputShellCommand 不支持 Unicode  
**解决**: 使用英文文本测试

### 3. 主题切换入口
**现象**: 首页和设置页均无主题切换按钮  
**状态**: 需确认代码中主题切换器位置
