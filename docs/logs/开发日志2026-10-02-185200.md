# 开发日志：修复安卓端同步 403 origin_forbidden

**日期**: 2026-10-02  
**类型**: Bug 修复（Android 原生端）  
**Runtime**: v54 → v55  

---

## 问题现象

手机端 App 右上角同步指示器一直显示红点（离线/失败），toast 反复提示"数据同步失败，将在恢复后重试"。Web 端一切正常。

## 根因

Qoder Sites 网关对 `/functions` 的请求强制校验 Origin：

| 请求 Origin | 结果 |
|-------------|------|
| 无 Origin | 403 `sites_gateway_origin_forbidden` |
| `https://localhost`（Capacitor WebView origin） | 403 |
| `https://my-schedule-akzzfsdx3vh.qoder.zone`（站点域） | 200 |

Web 端同源请求自动带站点 Origin，不受影响。原生端经 CapacitorHttp 的 fetch patch 发请求时，`Origin` 属于 forbidden header，被 `Request` 构造函数剥离，原生层收到的 headers 里没有 Origin → 网关全部拒绝 → 同步队列堆积、红点常驻。

设备日志证据（修复前）：

```
CapacitorHttp request ... headers:{"accept":...,"content-type":...}   ← 无 Origin
response {"status":403, "x-qoder-error":"sites_gateway_origin_forbidden",
          "data":{"code":"sites_gateway_origin_forbidden","message":"request origin is invalid"}}
```

## 修复

`src/lib/api.ts`：原生平台改走 `CapacitorHttp.request` 直连（原生层 headers 逐条 `setRequestProperty`，无 forbidden header 过滤），显式附带 `Origin: SITE_ORIGIN`；Web 平台保持原 fetch 路径不变。

`src/lib/config.ts`：抽出 `SITE_ORIGIN` 常量供两处复用。
