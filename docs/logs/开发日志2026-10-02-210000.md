# 开发日志 2026-10-02 #7

## 开屏动画「光迹 · Trace」

### 概述

为应用添加品牌化开屏动画，传递高级感、高效感与品牌一致性。采用纯 CSS+SVG 实现，不引第三方动画库。

### 设计概念

**光迹 · Trace**：一道发丝级光弧顺时针绘制到 300°（留缺口 = 进行中），尖端带拖尾辉光 → 弹簧落定脉冲 → 字标「我的日程」淡入上浮、字距由宽收窄、玻璃高光横扫一次 → 缺口补合成完整环 → 穿透式放大淡出进入首页。

### 双端变体

| 端 | 布局 | 时长 | 副标题 |
|----|------|------|--------|
| 桌面（≥768px） | 横向（弧左字右） | ≈1.9s | 显示「My Schedule」 |
| 手机（<768px） | 纵向（弧上字下） | ≈1.4s | 隐藏 |

### 主题适配

| 主题 | 底色 | 弧/辉光 | 高光手法 |
|------|------|---------|----------|
| Liquid Glass | `#f0f0f5` + 环境光斑 | primary 渐变弧 + 柔辉光 | 白色玻璃高光横扫 |
| Dark Glass | `#10101c` | primary `#8B9CF0`，辉光增强 | 淡 primary 光晕呼吸 |
| Neo Brutalism | `#fffef5` | 纯黑描边，无渐变无辉光 | 禁用柔光，硬切显影 |
| Paper Terminal | `#eae5d8` | navy `#2e3a8c` 单色弧，无辉光 | DotGothic16 逐点显影 |

### 动画阶段（桌面端时间轴）

| 阶段 | 时间 | 动作 |
|------|------|------|
| A 入场 | 0–200ms | 背景氛围光斑淡入；光弧容器淡入 |
| B 绘制 | 150–950ms | 光弧 `stroke-dashoffset` 从满到 300°；尖端辉光跟随 |
| C 落定 | 900–1150ms | 整体 scale 0.98→1.0 弹簧脉冲；字标淡入上浮 + 字距收窄 |
| D 高光 | 1150–1450ms | 玻璃高光横扫字标一次 |
| E 补合 | 1300–1600ms | 缺口 60° 平滑补合为完整环 |
| F 停留 | 1600–1750ms | 静止保持 |
| G 退出 | 1700–1900ms | 整体 scale 1.0→1.04 且 opacity 1→0，「穿透」露出首页 |

### 关键特性

- **主题感知**：挂载前读取 `getStoredTheme()`，写入 `data-theme` 属性，四套主题各自适配
- **就绪协调**：等待动画最短时长 **且** `state.status === 'ready'`，或硬上限 2500ms 强制退出
- **跳过支持**：点击/触摸（手机）或按键（桌面）可立即跳过至终态并退出
- **无障碍**：`prefers-reduced-motion: reduce` 下显示静态终态并平滑淡出；容器 `aria-hidden="true"`
- **性能**：仅动画 `opacity` / `transform` / `stroke-dashoffset`（GPU 友好）；无第三方依赖

### 验收

- 桌面端（Edge，系统深色开启）：横向构图，动画流畅，退出无硬切
- 移动端（浏览器工具，444px 视口）：纵向堆叠，副标题隐藏，动画流畅
- 四套主题：各自底色、弧色、辉光/高光手法符合设计规格
- TypeScript 编译：`tsc --noEmit` 通过
- 原生启动屏：时长缩短至 500ms，与 Web 动画交接无白闪（待真机验证）
