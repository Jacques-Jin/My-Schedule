# 开发日志 2026-10-01 #4

## 修复：Edge 深色模式下液态玻璃主题文字变白

### 问题

同一线上版本，夸克浏览器打开周课表字体为黑色（正常），Edge 打开字体变白色、看不清。

### 根因

`src/globals.css` 中存在 `@media (prefers-color-scheme: dark)` 媒体查询块，将 `--foreground` 覆盖为 `#ededed`（白）、`--background` 覆盖为 `#0a0a0a`（深）。

- Edge 遵循系统深色模式偏好，触发该媒体查询
- 夸克不遵循，因此不受影响

应用自带主题系统（Liquid Glass / Dark Glass / Neo-Brutalism / Paper Terminal），系统级深色偏好不应干扰应用主题。

### 修复

| 文件 | 改动 |
|------|------|
| `src/globals.css` | 删除 `@media (prefers-color-scheme: dark)` 整块；`:root` 增加 `color-scheme: light` 阻止浏览器暗色默认值 |
| `src/themes/dark-glass.css` | `[data-theme="dark-glass"]` 增加 `color-scheme: dark` 保证表单控件深色渲染 |
| `README.md` | Runtime v47 → v49 |
