# 开发日志 2026-10-01 #3

## 修复：数据同步失败（settings.save）

### 问题

部署 UUID 修复（v46）后，右上角同步指示器显示「数据同步失败」。

### 根因

`settings.save` handler 的 fields 列表包含 `theme`，但 settings 表只有 `id, remind_minutes, overlay_repeat` 三列。当用户切换主题时，`saveSettings({ theme: "dark-glass" })` 调用 API 失败（向不存在的列写入），被加入同步队列重试，再次失败。修复后的 `sync.ts` 正确将服务器错误报告为 `error` 状态（之前被错误地归类为「离线」并隐藏），因此用户看到了「同步失败」。

### 修复

| 文件 | 改动 |
|------|------|
| `functions/handler.mjs` | `settings.save` 将 DB 字段（`remind_minutes`, `overlay_repeat`）与 `theme` 分离；仅当存在 DB 字段时才操作数据库；theme-only 请求直接返回成功 |
| `README.md` | Runtime v46 → v47 |

### 修复逻辑

```javascript
// 之前：theme 混在 DB 字段里，导致向不存在的列写入
const fields = ["remind_minutes", "overlay_repeat", "theme"];

// 之后：DB 字段与 theme 分离
const dbFields = ["remind_minutes", "overlay_repeat"];
const dbData = pick(payload, dbFields);
if (Object.keys(dbData).length > 0) {
  // 有 DB 字段才操作数据库
} else {
  // theme-only，直接返回成功
}
```

### Runtime 版本

v46 → **v47**
