## 2. 后续 agent 接入指南（重点）

### 2.1 添加新主题只需两步

**第一步：创建 CSS 文件**

在 `src/themes/` 下新建 `{theme-id}.css`：

```css
/* src/themes/dark.css */

[data-theme="dark"] {
  --color-bg: #1a1a2e;
  --color-surface: #16213e;
  --color-text: #e0e0e0;
  --color-text-secondary: #a0a0b0;
  --color-primary: #7c3aed;
  --color-primary-light: #2d1b69;
  --color-border: #2a2a4a;
  --color-success: #34d399;
  --color-warning: #fbbf24;
  --color-danger: #f87171;
  --radius: 10px;
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.3);
  --shadow-md: 0 4px 12px rgba(0,0,0,0.4);
}

/* 如需覆盖特定组件样式： */
[data-theme="dark"] .task-item {
  /* 额外调整 */
}
```

**第二步：注册到 THEMES 数组**

编辑 `src/themes/registry.ts`，在 `THEMES` 数组中追加一条：

```typescript
export const THEMES: ThemeInfo[] = [
  { id: "default", name: "默认", description: "当前默认样式", cssFile: "" },
  { id: "dark", name: "深色模式", description: "暗色背景，护眼", cssFile: "dark.css" },
  // 继续追加...
];
```

**完成。** 无需修改其他任何文件。构建后用户即可在设置 → 外观中看到新主题卡片。

### 2.2 ThemeInfo 接口

```typescript
export interface ThemeInfo {
  id: string;        // 唯一标识，用于 data-theme 属性和 localStorage
  name: string;      // 显示名称（中文）
  description: string; // 简短描述
  cssFile: string;   // CSS 文件名（默认主题为空字符串）
  preview?: string;  // 可选：预览图路径
}
```

### 2.3 主题 CSS 编写规范

1. **选择器**：统一使用 `[data-theme="{id}"]` 前缀
2. **禁止** `!important`：`[data-theme]` 属性选择器优先级已足够
3. **禁止修改** `src/styles.css` 基础文件
4. **必须覆盖的变量**（`:root` 中定义的全部）：
   - `--color-bg` `--color-surface` `--color-text` `--color-text-secondary`
   - `--color-primary` `--color-primary-light` `--color-border`
   - `--color-success` `--color-warning` `--color-danger`
   - `--radius` `--shadow-sm` `--shadow-md`
5. **可选覆盖**：`--nav-height-top` `--nav-height-bottom`（一般不需要改）
6. **课程颜色**：`Course.color` 是用户数据中的 hex 值，不受 CSS 变量控制。深色主题下可用 `filter: brightness(0.8)` 或叠加遮罩处理
7. **硬编码颜色**：`styles.css` 中有少量硬编码值（如 `.task-priority.priority-高 { background: #fef2f2 }`），需在主题 CSS 中用 `[data-theme="xxx"] .task-priority.priority-高` 单独覆盖

### 2.4 CSS 加载方式

当前采用**静态导入**（适合主题数 ≤5）：
- 在 `src/main.tsx` 或 `App.tsx` 中 `import "./themes/dark.css"` 即可
- Vite 会将所有主题 CSS 打包到一个文件中，靠 `[data-theme]` 选择器隔离

如果未来主题数 >5，可切换为动态加载（`loader.ts` 已预留接口）：
```typescript
await import(`./themes/${themeId}.css`);
```

## 4. 已知限制

### 4.1 数据库 theme 列未添加

Qoder Sites 平台的 `create_database_migration` 工具当前**不支持 ALTER TABLE ADD COLUMN**（返回 `unsupported_ddl`）。因此生产数据库的 `settings` 表没有 `theme` 列。

**当前行为**：
- 主题选择通过 `localStorage` 持久化（单设备有效）
- `handler.mjs` 的 bootstrap 在 settings 行缺少 theme 时自动补充 `"default"`
- `settings.save` 接受 theme 参数但不写入数据库（列不存在）
- 前端状态正常更新，用户体验无感知差异

**未来修复**：当平台支持 ALTER TABLE 后，执行：
```sql
ALTER TABLE settings ADD COLUMN theme text;
```
然后将 `handler.mjs` 中 settings.save 的 fields 改回 `["remind_minutes", "overlay_repeat", "theme"]`，bootstrap 的列选择改回 `"id,remind_minutes,overlay_repeat,theme"`。

### 4.2 跨设备同步

由于 4.1，主题偏好目前**不能跨设备同步**。换设备或清除浏览器数据后会回到默认主题。

## 5. 数据流图

```
用户点击主题卡片
    │
    ├─→ applyTheme(id)
    │     ├─ document.documentElement.setAttribute("data-theme", id)
    │     └─ localStorage.setItem("app-theme", id)
    │
    └─→ saveSettings({ theme: id })
          └─→ api.settingsSave → handler.mjs → Supabase（当前不写入 theme 列）
               └─→ dispatch({ type: "update_settings", data: row })

页面加载时：
    index.html 内联脚本 → 读 localStorage → 设置 data-theme（防闪烁）
        ↓
    React mount → bootstrap → settings.theme（服务端返回，当前始终为 "default"）
        ↓
    App.tsx useEffect → applyTheme(state.settings.theme)
```
