## 变更内容

### 1. 作业系统 Bug 修复

#### 1.1 课程 ID 类型不匹配（"未知课程"问题）
- **问题**：IndexedDB 中 `course.id` 为数字，`homework.course_id` 为字符串，严格等于 `===` 比较失败
- **修复**：所有课程 ID 比较统一使用 `String()` 转换（HomeworkList.tsx、HomeworkPage.tsx）
- **文件**：`src/components/homework/HomeworkList.tsx`、`src/pages/HomeworkPage.tsx`

#### 1.2 课程详情作业不显示
- **问题**：同一课程多个时间段对应不同 ID，作业绑定其中一个 ID 后，查看另一时间段课程时匹配不到
- **修复**：改为按课程名称匹配——先解析 courseId → 课程名 → 所有同名课程 ID 集合，再用集合过滤作业
- **文件**：`src/components/homework/HomeworkList.tsx`（`allMatchIds` useMemo）

#### 1.3 课程下拉去重 + 教师名显示
- **问题**：同一课程多个时间段在下拉菜单和筛选标签中重复出现
- **修复**：按课程名称去重，聚合同名课程的教师信息，显示格式为"课程名（教师1、教师2）"
- **文件**：`src/components/homework/HomeworkList.tsx`（`availableCourses`）、`src/pages/HomeworkPage.tsx`（`coursesWithHomework`）

### 2. 时间指示线修复
- **问题**：周课表当前时间指示线不显示
- **修复**：采用 wrapper 模式 + `position: relative` 确保指示线正确定位
- **文件**：`src/pages/SchedulePage.tsx`、`src/styles.css`
