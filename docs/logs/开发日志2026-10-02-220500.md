# 开发日志 2026-10-02 22:05 — v58 开屏文字不可见修复（主题令牌冷启动缺口）

## 现象
深色主题（Dark Glass）下，网页版与 App 版开屏动画的「我的日程 / My Schedule」文字从头到尾完全不可见；浅色主题下正常。

## 根因
主题 CSS 以运行时 `<link href="/themes/*.css">` 方式加载，且只在 `applyTheme()` 被调用时注入（App 数据 ready 之后）。而 `index.html` 的内联启动脚本在首帧就设置了 `html[data-theme]`：
- 开屏背景由 splash.css 的 `[data-theme="dark-glass"] .splash-root` 覆盖为近黑 `#10101c`；
- 但 `--color-text` 等令牌仍来自 styles.css 的浅色 `:root` 定义（主题 CSS 尚未加载）；
- 结果：深色背景 + 浅色主题墨色文字（#1d1d1f）= 文字不可见。

## 修改
- `src/splash.css`：为开屏根节点自身补充同元素主题令牌（`[data-theme="x"].splash-root { --color-text / --color-text-secondary / --color-primary / background }`），覆盖 dark-glass、neo-brutalism、paper-terminal，使开屏不依赖延迟加载的主题 CSS。
- `index.html`：启动脚本在设置 `data-theme` 的同时同步注入对应 `/themes/*.css` 样式表，消除整站冷启动的主题缺口（含开屏之后的首屏）。

## 验证
- 浏览器注入 mock `.splash-root[data-theme="dark-glass"]`：标题 `rgb(245,245,247)`、副标题 `rgb(180,180,196)`、背景 `rgb(16,16,28)` —— 深底浅字，可见。
- 启动后 `link[data-theme]` 存在，`html[data-theme]` 正确。
