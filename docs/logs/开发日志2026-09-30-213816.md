## 1. 本次完成的工作

### 1.1 功能概述
新增第四套完整主题 **Paper Terminal（纸面终端 / 点阵仪器风）**，设计语言为「纸面终端 + 合成器面板」，灵感来自 Teenage Engineering 设备手册、老式示波器界面与点阵打印规格表。整体氛围冷静、精密、复古实验室感——「一台会思考的老仪器」。

### 1.2 设计原则对照

| # | 用户要求 | 实现方式 |
|---|----------|----------|
| 1 | 三层字体 | 显示层 DotGothic16（点阵）→ 标签/编号层 JetBrains Mono（等宽）→ 正文层 Inter / Noto Sans SC（中性无衬线）；层级靠字号与字距而非加粗 |
| 2 | 零圆角 + 1px 细边框 | 全部 `--radius*` 设 `0px`；面板 `1px solid #1F1D1A`；嵌套面板用缩进 + 分隔线，如工程规格表 |
| 3 | 极度克制配色 | 奶油纸 `#EAE5D8`、暖黑墨 `#1F1D1A`、唯一强调藏蓝 `#2E3A8C`、辅助灰 `#8A8578`；禁渐变禁多彩，靠单色 + 反白制造层级 |
| 4 | 选中/激活反白 | 活动态 = 藏蓝填充 + 纸色文字，或 2px 藏蓝边框 + 内嵌 `▸` 刻度；未选中为细灰边框；切换无过渡 |
| 5 | 方块徽标编号 | 导航 / 分类使用 16px 正方形深色徽标 + 白色等宽字母 A–F，与文字左对齐形成目录感 |
| 6 | 点阵数据可视化 | 进度条用 `repeating-linear-gradient` 生成 2px 宽 / 2px 间距的藏蓝细竖条，如示波器采样；禁圆头禁渐变 |
| 7 | 极简机械交互 | hover 仅切换边框粗细或出现 `▸` 前缀；点击瞬间反白；输入光标为闪烁方块 `▌`；动效 `steps()` / 0ms |
| 8 | 纸面背景 | 纯色奶油纸 + 极淡横向刻度线（透明度 5%）；版面留白大方 |
| 9 | 仪器说明书文案 | 各页标题加 `01 /`–`06 /` 编号前缀；标签等宽小字；任务分组用 `01 /`、`02 /` 计数器 |
| 10 | 移动端优先 | 面板单列堆叠；点阵标题在小屏降为等宽字体避免糊边；触控目标 ≥44px |

### 1.4 设计令牌（Design Tokens）

```css
[data-theme="paper-terminal"] {
  /* 纸面三色 + 唯一强调 */
  --pt-paper: #eae5d8;   /* 奶油纸 */
  --pt-ink:   #1f1d1a;   /* 暖黑墨 */
  --pt-navy:  #2e3a8c;   /* 藏蓝（唯一强调） */
  --pt-aux:   #8a8578;   /* 辅助灰 */
  --pt-sec:   #6f6a5b;   /* 次级正文灰（见 1.6 偏差说明） */

  /* 三层字体 */
  --pt-display: "DotGothic16", "JetBrains Mono", ui-monospace, monospace;
  --pt-mono:    "JetBrains Mono", "IBM Plex Mono", ui-monospace, monospace;
  --pt-body:    "Inter", "Noto Sans SC", -apple-system, sans-serif;

  /* 去玻璃化 */
  --glass-bg: var(--pt-panel); --glass-blur: 0px;
  --glass-shadow: none; --glass-highlight: none;

  /* 零圆角 / 无阴影 / 无缓动 */
  --radius: 0px; --radius-sm: 0px; --radius-lg: 0px; --radius-pill: 0px;
  --shadow-sm: none; --shadow-md: none; --shadow-lg: none;
  --ease: steps(1, end); --ease-spring: steps(1, end);
  --dur-fast: 0ms; --dur: 0ms; --dur-slow: 0ms;
}
```

### 1.5 关键样式特征

- **全局去玻璃化**：`[data-theme="paper-terminal"] * { backdrop-filter: none !important; }`。
- **编号目录感**：各页 `h2` 通过 `::before` 计数器加 `01 /`–`06 /` 前缀；任务分组 `counter(ptg)` 生成 `01 /`、`02 /`。
- **方块徽标**：底部 / 顶部导航标签 `::before` 生成 16px 黑底白字等宽字母 A–F；活动态徽标反白为藏蓝。
- **闪烁方块光标**：首页日期 `::after` 输出 `▌`，`steps(1,end)` 1s 无限闪烁；输入框 `caret-shape: block`。
- **示波器进度条**：`.campaign-progress-fill` 用 `repeating-linear-gradient(90deg, navy 0 2px, transparent 2px 4px)` 生成采样竖条。
- **周课表规格表**：网格 `background: var(--pt-aux)` + 1px gap 形成灰色细线；今天表头藏蓝反白；课程块藏蓝实底 + 纸色等宽字。
- **▸ 悬停前缀**：任务 / 时间线 / 待办 / 设置 / 战役 / 作业各行 `::before` 默认透明 `▸`，hover 变藏蓝。

### 1.6 偏差与限制说明

1. **次级正文灰 `--pt-sec: #6f6a5b`**：用户给定的辅助灰 `#8A8578` 在奶油纸底上对比度偏低，直接用于次级正文会影响可读性。故保留 `#8A8578` 仅用于刻度线 / 占位符 / 禁用态，另引入略深的 `#6f6a5b` 作为次级正文色，仍在暖灰单色系内。
2. **点阵字体 CJK 限制**：DotGothic16 为日文字体，不含简体中文字形，中文标题会回退到字体栈下一位（等宽 / 无衬线）。数字与拉丁字符仍呈现点阵质感。此为字体本身限制，已通过字体栈顺序与移动端等宽回退缓解。
3. **内联颜色覆盖**：分类 / 战役 / 课程的颜色以 inline style 注入（`CATEGORY_COLORS`、`campaign.color`、`course.color`）。为维持单色 + 反白，主题对这些选择器使用 `!important` 强制覆盖为藏蓝 / 暖黑 / 描边样式。
