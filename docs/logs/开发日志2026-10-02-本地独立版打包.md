# 开发日志 2026-10-02 · 本地独立运行版打包

## 背景

用户询问：`启动.bat` 打开的本地网页版是否与线上端、APP 端同步数据？
答案：**不同步**。三端数据互相隔离：

| 端 | 数据来源 | 服务端 |
|---|---|---|
| 本地开发版（5173） | 浏览器 IndexedDB（源 127.0.0.1:5173） | Deno 内存假 Supabase（:8000，重启即重置为种子） |
| 线上站点 | 浏览器 IndexedDB（源 qoder.zone） | Sites 边缘函数 → Supabase |
| 安卓 APP | WebView IndexedDB（源 capacitor://localhost） | 线上 Supabase（绝对地址） |

IndexedDB 按浏览器源隔离；本地版后端是内存假库，从不触达 Supabase。

## 交付：本地独立运行版（免开发环境）

用户要求"打包一个完整的本地运行版本"。产出自包含包，拷到任意
Windows 电脑双击即用，无需 Node/npm/Deno 环境：

```
MySchedule-Local/
├── deno/deno.exe        # 内置 Deno 2.1.4 运行时
├── server/server.ts     # 单端口 8100：静态前端 + 假 Supabase API
├── server/handler.mjs   # 与线上同一份 API 处理器（含 SEED）
├── app/                 # v62 前端构建产物（dist）
├── 启动本地版.bat        # 启动（含 8100 占用守卫）+ 自动开浏览器
├── stop-local.bat       # 停止
└── README.txt           # 使用说明与数据隔离声明
```

- 服务器为单端口合并方案：`/functions/v1/app*` 走 handleRequest + 内存假库，
  其余路径静态服务 `app/`（含 SPA 回退 index.html）。
- 模板源在 `scripts/local-package/`；组装脚本 `scripts/build-local-package.mjs`
  （dist → app、拷 deno.exe/handler.mjs/模板 → `output/MySchedule-Local`，
  并压缩为 `output/我的日程-本地版-v62.zip`，约 48MB）。
- `output/` 已加入 .gitignore。

## 验证记录

1. 静态：`/`、`/assets/index-BktSKcLL.js`、`/themes/dark-glass.css` 均 200。
2. API：`?action=seed.ifEmpty` → `{"ok":true,...}`（action 走查询参数，非 body）。
3. 浏览器：开屏动画正常播放，首页渲染种子时间线/待办/底部导航，无控制台报错。
4. `启动本地版.bat`：冷启动拉起服务器（端口 8100 LISTENING）；
   `stop-local.bat`：端口释放。

## 影响面

- 不改任何应用代码，Runtime 保持 v62。
- 与开发版（5173/8000）可并存，数据互不相通。
