# 开发日志 2026-10-01 #2

## 修复：主题切换 + 同步指示器

### 问题

1. **线上版本无法切换主题**：`src/themes/loader.ts` 中使用 `/src/themes/${cssFile}` 路径，仅在 Vite 开发服务器中有效，生产构建后该路径不存在。
2. **右上角始终显示"离线"**：`sync.ts` 将所有 API 错误归类为网络错误（offline），实际上 settings.save 返回 503 是因为 settings 表缺少 theme 列，属于服务器错误。

### 修复

| 文件 | 改动 |
|------|------|
| `src/themes/loader.ts` | 路径从 `/src/themes/` 改为 `/themes/`，匹配生产构建输出 |
| `public/themes/*.css` | 将三套主题 CSS 复制到 `public/` 目录，Vite 构建时自动拷贝到 `dist/themes/` |
| `src/lib/sync.ts` | 区分 TypeError（网络错误→offline）和其他错误（服务器错误→error）；队列清空后自动恢复到 synced |
| `functions/handler.mjs` | settings.save 的 fields 增加 `theme` 字段（为未来数据库迁移做准备） |

### 同步状态机改进

```
syncing → 成功 → synced
syncing → TypeError → offline（等待网络恢复）
syncing → 服务器错误 → error（移除队列项，队列空则自动恢复 synced）
```

### 已知限制

- settings 表缺少 `theme` 列，数据库迁移被平台拒绝（unsupported_ddl）
- 主题已通过 localStorage 持久化，功能不受影响
- 同步指示器不再因 settings.save 失败而卡在"离线"
