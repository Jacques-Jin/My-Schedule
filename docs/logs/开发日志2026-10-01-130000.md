# 开发日志 2026-10-01 #2

## 修复：主题切换 + 同步指示器 + 云端写入

### 问题

1. **线上版本无法切换主题**：`src/themes/loader.ts` 中使用 `/src/themes/${cssFile}` 路径，仅在 Vite 开发服务器中有效，生产构建后该路径不存在。
2. **右上角始终显示"离线"**：`sync.ts` 将所有 API 错误归类为网络错误（offline），实际上 settings.save 返回 503 是因为 settings 表缺少 theme 列，属于服务器错误。
3. **数据无法同步到云端（跨设备不可见）**：数据库所有表的 `id` 列缺少 `DEFAULT gen_random_uuid()`，handler 插入时不提供 `id` 导致 NOT NULL 约束违反，所有写入操作返回 503。本地 IndexedDB 有数据但云端为空，手机打开看不到任何新增内容。
4. **同步失败误报成功**：server error 后队列清空时状态被设为 "synced"，触发"数据同步成功"toast，实际数据从未到达服务器。

### 修复

| 文件 | 改动 |
|------|------|
| `src/themes/loader.ts` | 路径从 `/src/themes/` 改为 `/themes/`，匹配生产构建输出 |
| `public/themes/*.css` | 将三套主题 CSS 复制到 `public/` 目录，Vite 构建时自动拷贝到 `dist/themes/` |
| `src/lib/sync.ts` | 区分 TypeError（网络→offline）和其他错误（服务器→error）；server error 不再误报 synced |
| `functions/handler.mjs` | 所有 insert 操作添加 `id: crypto.randomUUID()`；settings.save 增加 theme 字段 |

### 根因分析：云端写入失败

```
 Supabase insert({ title, course_id, ... })
→ PostgreSQL: id 列 NOT NULL 且无 DEFAULT
→ ERROR 23502: null value in column "id" violates not-null constraint
→ handler 捕获后返回 503
→ 前端 catch → 入队 sync queue
→ sync 重试同样失败 → 移除队列 → 误报 "synced"
```

修复后：handler 为每个 insert 生成 `id: crypto.randomUUID()`，写入成功。

### 同步状态机改进

```
syncing → 全部成功 → synced
syncing → TypeError → offline（保留队列，等待网络恢复）
syncing → 服务器错误 → error（移除失败项，不再误报 synced）
```
