## 1. 问题背景（用户反馈）

首页右上角"＋添加"等实心主色按钮颜色"惨白"（`#8B9CF0` 明度过高、饱和度不足），
希望向**纯色**方向调整。

## 2. 修复方案（仅改动 `src/themes/dark-glass.css`）

新增纯色令牌：

```css
--color-primary-solid: #4E5FE6;        /* 高饱和纯靛蓝 */
--color-primary-solid-hover: #6272F0;
```

- 实心主色按钮统一改用纯色：
  `.home-add-btn / .tasks-add-btn / .tb-btn-primary / .cf-save / .tf-btn.primary / .btn-primary`
  → `background: var(--color-primary-solid)`，悬停 `--color-primary-solid-hover`，
  配靛蓝投影 `0 2px 10px rgba(78,95,230,0.45)`。
- 选中态 pill（`.filter-chip.active / .view-btn.active / .settings-tab.active /
  .nav-tab.active / .cf-wd-btn.active / .tf-wd-btn.active / .tf-week-btn.active /
  .day-chip.active`）由浅靛蓝渐变改为同一纯色，视觉语言统一。
- 文字类强调色（导航激活标签、链接、focus ring 等）仍保留 `--color-primary: #8B9CF0`，
  保证深色背景上的可读性；仅"填充色"纯色化。

## 3. 验证结果

浏览器 computed style 实测：`.home-add-btn` 背景 = `rgb(78, 95, 230)`（#4E5FE6），
文字 = `#fff`。✅

> 注：验证时应用内浏览器窗口被隐藏，无法截图；结论基于 computed style 检查。
