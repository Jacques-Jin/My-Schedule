# 功能方案：课表当前时间指示线

- 创建时间：2026-09-30
- 状态：方案阶段（未实施）
- 优先级：中

---

## 1. 需求描述

在周课表和日课表上显示一条**不显眼的横线**，指示当前时间位于一天的哪个部分。用户一眼即可知道"现在上到第几节了"。

### 1.1 设计原则

- **低调**：线条细、颜色淡，不抢课程色块的视觉焦点
- **精准**：位置对应当前时刻在节次时间轴上的真实比例
- **仅今天**：只在"今天"所在的列/区域显示，非今天不显示
- **自动更新**：每分钟刷新一次位置，无需用户操作
- **节假日隐藏**：如果今天是节假日（放假），不显示指示线

---

## 2. 现状分析

### 2.1 周视图（WeekView）

- 布局：CSS Grid，`grid-template-columns: 48px repeat(7, 1fr)`，`grid-template-rows: auto repeat(14, minmax(40px, 1fr))`
- 第 1 行 = 日期表头，第 2–15 行 = 第 1–14 节课
- 每个格子通过 `gridRow: slot_no + 1`、`gridColumn: colIdx + 2` 定位
- 节次时间来自 `periodSlots`（如第 1 节 08:00–08:45，第 2 节 08:55–09:40…）
- 课程色块（CourseBlock）绝对定位覆盖在格子上方
- **"今天"列**已通过 `d === today` 判断，表头有 `.today` 高亮

### 2.2 日视图（DayView）

- 布局：卡片流式排列，按上午/下午/晚上分组（`day-groups`）
- 无时间轴网格，不适合放精确横线
- 每组内课程卡片按节次排列
- 适合用**高亮当前时段组**或**组间"现在"标记**的方式指示

### 2.3 时间数据

- `periodSlots`：每节课的 `start_time` / `end_time`（"HH:MM" 格式）
- 节次之间可能有间隙（如 08:45–08:55 课间）
- 第 14 节之后无数据（晚间无课则不显示）

## 3. 技术方案

### 3.1 周视图：绝对定位横线

**核心思路**：在 `.week-grid` 容器内渲染一个绝对定位的横线元素，横跨"今天"所在列。

**位置计算**：

```
当前分钟数 = now.getHours() * 60 + now.getMinutes()

遍历 periodSlots，找到当前时间落入的区间：
  - 若 start_time ≤ now ≤ end_time → 在该节次内部
    比例 = (now - start_time) / (end_time - start_time)
    顶部偏移 = (slot_no - 1) * rowHeight + 比例 * rowHeight
  - 若 now 落在两节之间的间隙 → 取前一节末尾位置
  - 若 now < 第1节 start_time → 不显示（还没开始上课）
  - 若 now > 最后节 end_time → 不显示（已下课）
```

**rowHeight 获取**：由于 grid 行高是 `minmax(40px, 1fr)`，实际高度不固定。方案：
- 用 `ref` 获取 `.week-grid` 元素，读取 `gridTemplateRows` 计算值
- 或：获取任意一个 `.wg-cell` 的 `offsetHeight` 作为行高基准
- 或：将指示线放在对应行内，用 `position: absolute; top: X%` 相对于该行定位（**推荐**，无需知道绝对像素）

**推荐方案（行内百分比定位）**：
- 找到当前时间所在的 slot_no
- 在对应的 grid 行内渲染一个 `position: absolute` 的横线
- `top` 值 = 该节次内的时间比例 × 100%
- `left: 0; right: 0`（横跨整行）或仅横跨今天列

**仅横跨今天列的实现**：
- 横线元素的 `gridColumn` 设为今天对应的列号（colIdx + 2）
- `gridRow` 设为当前节次行号（slot_no + 1）
- 在格子内 `position: absolute; top: X%; left: 0; right: 0`

### 3.2 日视图：当前时段高亮 + "现在"标记

日视图无时间网格，采用两种互补方式：

1. **当前时段组高亮**：判断当前时间属于上午/下午/晚上哪个区间，给对应的 `.day-group` 添加 `.now-group` 类，左侧加一条竖线或背景微亮
2. **"现在"文字标记**：在当前正在进行的课程卡片旁（或两个时段组之间）显示一个小标签 `● 现在`

### 3.3 时间更新机制

```typescript
// 自定义 hook：useNow(intervalMs = 60000)
function useNow(interval = 60000) {
  const [now, setNow] = useState(() => new Date());
  useEffect(() => {
    const id = setInterval(() => setNow(new Date()), interval);
    return () => clearInterval(id);
  }, [interval]);
  return now;
}
```

- 每 60 秒更新一次（分钟级精度足够）
- 组件卸载时清除 interval
- 放在 SchedulePage 顶层，通过 props 传给 DayView / WeekView

### 3.4 边界情况处理

| 场景 | 行为 |
|------|------|
| 当前时间早于第 1 节开始 | 不显示指示线 |
| 当前时间晚于最后节结束 | 不显示指示线 |
| 当前时间在课间间隙 | 显示在前一节末尾位置（或两节之间） |
| 今天是节假日 | 不显示 |
| 查看的不是本周 | 不显示（today 不在 dates 中） |
| 日视图查看的不是今天 | 不显示 |
| periodSlots 为空 | 使用默认 PERIOD_SLOTS 计算 |

### 4.2 时间定位工具函数

```typescript
// src/lib/time-indicator.ts
import type { PeriodSlot } from "./date";

export interface NowPosition {
  slotNo: number;   // 当前所在节次（1-based）
  ratio: number;    // 在该节次内的比例（0~1）
}

function toMinutes(timeStr: string): number {
  const [h, m] = timeStr.split(":").map(Number);
  return h * 60 + m;
}

/**
 * 计算当前时间在节次时间轴上的位置。
 * 返回 null 表示不在任何节次范围内（太早/太晚/课间）。
 */
export function getNowPosition(now: Date, slots: PeriodSlot[]): NowPosition | null {
  const nowMin = now.getHours() * 60 + now.getMinutes();
  const sorted = [...slots].sort((a, b) => a.slot_no - b.slot_no);

  for (const slot of sorted) {
    const start = toMinutes(slot.start_time);
    const end = toMinutes(slot.end_time);
    if (nowMin >= start && nowMin <= end) {
      const ratio = end > start ? (nowMin - start) / (end - start) : 0;
      return { slotNo: slot.slot_no, ratio };
    }
  }

  // 课间间隙：返回前一节末尾
  for (let i = 0; i < sorted.length - 1; i++) {
    const endThis = toMinutes(sorted[i].end_time);
    const startNext = toMinutes(sorted[i + 1].start_time);
    if (nowMin > endThis && nowMin < startNext) {
      return { slotNo: sorted[i].slot_no, ratio: 1 };
    }
  }

  return null; // 不在上课时间范围内
}

/**
 * 判断当前时间属于上午/下午/晚上哪个时段。
 * 用于日视图高亮。
 */
export function getNowDayPart(now: Date, slots: PeriodSlot[]): "morning" | "afternoon" | "evening" | null {
  const pos = getNowPosition(now, slots);
  if (!pos) {
    // 课间也判断
    const nowMin = now.getHours() * 60 + now.getMinutes();
    const sorted = [...slots].sort((a, b) => a.slot_no - b.slot_no);
    if (sorted.length === 0) return null;
    const first = toMinutes(sorted[0].start_time);
    const last = toMinutes(sorted[sorted.length - 1].end_time);
    if (nowMin < first || nowMin > last) return null;
  }
  const slotNo = pos?.slotNo ?? 0;
  if (slotNo <= 5) return "morning";
  if (slotNo <= 10) return "afternoon";
  return "evening";
}
```

### 4.3 周视图集成

在 `WeekView` 组件中：

```tsx
// 接收 now prop
const nowPos = useMemo(() => {
  if (!dates.includes(today)) return null;  // 不是本周
  const todayType = getDayType(today);
  if (todayType.isHoliday) return null;     // 节假日
  return getNowPosition(now, periodSlots);
}, [now, dates, today, periodSlots]);

// 在 grid 内渲染（与 CourseBlock 同级）
{nowPos && (
  <div
    className="wg-now-line"
    style={{
      gridRow: nowPos.slotNo + 1,
      gridColumn: dates.indexOf(today) + 2,
      top: `${nowPos.ratio * 100}%`,
    }}
  />
)}
```

注意：`.wg-now-line` 需要 `position: relative` 的父容器。由于 grid 子元素默认 `position: static`，需要给该行格子加 `position: relative`（已有 `.wg-cell { position: relative }`），或者将指示线作为独立 grid item 并用 `align-self: start` + `margin-top` 定位。

**更稳妥的方案**：将指示线渲染为 grid 的直接子元素，设置 `gridRow` 和 `gridColumn`，自身 `position: relative`，内部用伪元素或子 div 做 `position: absolute; top: X%`。

## 7. 风险与注意事项

### 7.1 Grid 行高不固定

`grid-template-rows: auto repeat(14, minmax(40px, 1fr))` 意味着行高随容器变化。使用**百分比定位**（`top: X%`）相对于格子自身高度，无需知道绝对像素值。

### 7.2 课程色块遮挡

CourseBlock 的 z-index 需确认高于指示线。当前 `.course-block` 无显式 z-index，指示线设 `z-index: 5`，课程色块默认在 grid 流中后渲染会覆盖。如需确保，可给 `.course-block` 加 `z-index: 10`。

### 7.3 跨午夜

如果用户在 23:59 打开页面，interval 到 00:00 后 `today` 变化，指示线应消失（新的一天还没到上课时间）。`useNow` 每分钟更新会自动处理。

### 7.4 periodSlots 为空

使用 `PERIOD_SLOTS` 默认值兜底（SchedulePage 已有此逻辑：`pSlots`）。

### 7.5 与主题系统兼容

指示线颜色使用固定 rgba 值（不依赖 CSS 变量），确保在任何主题下都可见。如果后续主题需要定制，可改为 `var(--color-danger)` + opacity。
