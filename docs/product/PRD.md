## 1. 产品目标和使用场景

### 1.1 产品目标
为北航中法未来试验班大一学生（个人使用）提供一站式日程管理：把**学校课表、校历节假日、个人待办/活动、多日备考计划**汇总在一个网页应用中，手机和电脑浏览器均可访问，数据云端持久保存。

### 1.2 使用场景
- 早上出门前打开首页，看今天上什么课、在哪上、几点上，以及今天要完成的待办。
- 上课前收到浏览器提醒，避免走错教室或迟到。
- 随时添加/勾选待办（作业、考试、社团、生活）。
- 翻课表查某门课第几周、在哪上、老师是谁；切换周次和学期查看。
- 备考四级等长期目标：把分散在多天的零散子计划归入一个「战役计划」，在一个窗口内总览、批量操作，子计划与战役之间可双向跳转。
- 节假日/调休自动标注，假期日不显示课程。

### 1.3 约束与前提
- 仅个人使用：**无注册登录、无社交功能**。
- 部署为线上网页（Qoder Sites），数据存云端数据库；隐私靠**链接不公开**保护。
- 手机（≤768px）与电脑（>768px）响应式适配。
- 课表、节次时间、校历节假日由开发时**预置录入**（数据源：`课表集/` 目录下的学期课表.xlsx、周课表.xlsx、课程表-手搓.xlsx、校历.jpg，解析明细见 `parsed_schedules.txt`），用户无需手动录课表。

## 2. 整体页面框架和导航结构

### 2.1 页面清单
| 页面 | 说明 |
|---|---|
| 首页 | 今日总览（时间线 + 待办 + 倒计时） |
| 课表 | 日视图（默认）/ 周视图，周次与学期切换 |
| 日程 | 待办/活动清单，增删改、筛选、批量操作 |
| 战役 | 战役计划列表 + 战役详情窗口（子计划总览与批量操作） |
| 设置 | 学期管理、校历节假日、作息时间、提醒、数据备份 |

浮层组件：课程详情卡、日程编辑表单、战役编辑表单、提醒横幅、二次确认对话框。

### 2.2 导航
- 手机端：底部 5 Tab —— 首页 / 课表 / 日程 / 战役 / 设置。
- 桌面端：顶部导航栏（同 5 项），内容区居中限宽。
- 全局返回逻辑：浮层关闭回原页面；战役详情 ←→ 子计划（日程编辑/日程列表定位）双向跳转。

### 2.3 响应式规则
- ≤768px：底部 Tab；课表默认日视图；表单用底部抽屉；列表单列。
- >768px：顶部导航；课表默认周视图网格；首页三栏（时间线 / 待办 / 焦点+倒计时）；表单用右侧抽屉。

## 3. 首页的内容结构

自上而下（手机端）：
1. **日期头部**：公历日期、星期、第 X 周；当天为节假日时显示红色徽章（如「国庆节」）。
2. **下一节课焦点卡**：课程名、节次与起止时间、教室、距开课倒计时（实时）；当天无剩余课程时显示「今天没有课了」或下一上课日信息。
3. **今日时间线（今日计划）**：把当日课程、当日日程实例（含重复日程展开实例、个人固定作息）**按开始时间混排**；当前时段高亮、已过条目置灰；课程条目点击弹课程详情卡，日程条目点击进编辑；底部「＋添加」快速新建今日日程。
4. **今日待办**：今日到期日程的勾选清单，显示完成进度 n/m；勾选即完成。
5. **倒计时条**（次要）：横向滑动 chips，预置节假日/寒假倒计时 + 用户自定义倒计时（如考试日）；点击可管理。

桌面端三栏：左=今日时间线，中=今日待办，右=焦点卡+倒计时+本周缩略课表。

## 4. 每个模块的用途

### 4.1 首页
用途：每天打开的第一屏，回答「今天什么时候、在哪里、做什么」。聚合所有模块的当日投影，不做数据管理。

### 4.2 课表
用途：查看课程安排。
- 顶栏：`‹ 第X周 ›` 周切换、「回到本周」、学期下拉。
- 视图切换分段控件 `[日 | 周]`，**手机端默认日视图，桌面端默认周视图**；切换控件常驻顶栏，一键互切。
- 日视图：顶部周一至周日 7 个日期 chip（含日期数字，选中实心），下方按上午/下午/晚上分组的当日课程卡片（节次、起止时间、课程名、教室）；左右滑动换天；非本周有课的其他周课程以虚线灰卡提示。
- 周视图：7 列 × 14 节网格，课程块按节次跨度占位、每门课固定配色，块内显示课程名+教室；非本周课程虚线灰块；节假日列整列淡色遮罩并显示节日名。
- 开关：「在课表上显示我的重复日程」——把带重复规则的个人日程以浅色叠进网格。
- 交互：点课程块 → 课程详情卡（教师、周次范围、节次与时间、教室、备注、按钮「查看第 X 周」「＋建日程」）；长按/点空白格 → 以该时段预填新建日程。

### 4.3 日程
用途：管理全部待办/活动（课程以外的所有事情）。
- 筛选 chips：全部/今天/未完/已逾期/已完成；分类下拉；搜索框。
- 列表按日期分组：今天/明天/本周/更早/已完成（折叠）。
- 条目：勾选圈、标题、时间、分类色 tag、优先级角标、重复图标、战役归属标记（点击标记直达所属战役）。
- 编辑表单字段：标题*、日期、起止时间、分类（作业/考试/学习/生活/社团/自定义）、优先级（高/中/低）、重复规则（不重复/每天/每周几/每两周/自定义周次）、提醒（不提醒/准时/提前10/30/60分钟）、归属战役（可选）、备注。
- 批量操作：进入多选模式后批量 完成/删除/改期/改分类。

### 4.4 战役（战役计划）
用途：把分散在多天的多个零散子计划（如「备考四级」）聚合到一个易操作的窗口。
- 战役列表页：战役卡片（名称、目标/截止日、进度 n/m、颜色、最近子计划日期）；「＋新建战役」。
- 战役详情窗口（核心）：
  - 头部：战役名、目标描述、截止日倒计时、总进度条。
  - 子计划列表：按日期分组展示该战役全部子计划（即带 campaignId 的日程），每条显示日期、标题、状态；勾选圈可完成。
  - **双向跳转**：点子计划 → 打开该日程的编辑表单（可改日期/内容/脱离战役）；从任何带战役标记的日程 → 一键进入所属战役详情。
  - **批量操作栏**：多选子计划后批量 完成/删除/移动到某日/加入今天/改分类；支持「批量新建」（一次录入多条子计划，逐条填标题+日期）。
  - 快捷操作：「＋加子计划」（新建并自动归属）、「把现有日程拉入战役」（从日程列表多选挂载）。
- 战役编辑表单：名称*、目标/备注、截止日（可选）、颜色。

### 4.5 设置
用途：维护基础数据与偏好。
- 学期管理：学期列表（名称、第 1 周周一、总周数、启用标记）；新建/切换当前学期；课表与首页随当前学期变化。
- 校历节假日：日期+名称列表（支持单日或起止区间），增删改；预置 2026 秋：中秋 9/20、国庆 10/1-10/4、校运会 10/16、元旦 1/1、寒假起止（按校历.jpg 录入，用户可改）。
- 作息时间表：14 节节次起止时间，可编辑；预置校历时间（08:00-08:45 … 21:30-22:15）。
- 提醒：上课提醒提前量（默认 10 分钟）、日程提醒默认值、浏览器通知授权按钮、「课表叠显示重复日程」开关。
- 数据：导出 JSON 备份、导入恢复。

### 4.6 提醒机制（全局）
- 页面打开期间每分钟检查：到达提醒时间的课程/日程 → 顶部滑入提醒横幅 + 浏览器 Notification（首次访问请求授权）。
- 页面关闭时不推送（第一版限制，见第 8 章）。

## 6. 首页、今日计划和各模块之间的关系

- **今日计划（首页时间线）是投影，不是数据源**：它由三部分实时合成——①课表模块中「周次规则命中今天」的课程；②日程模块中「今天到期」的日程实例（含重复规则展开、战役子计划）；③设置中叠显示开关控制的个人固定作息。任何模块的数据修改立即反映到首页，首页不单独存数据。
- **首页 → 模块**：点课程条目 → 课程详情卡（课表模块数据）；点日程条目 → 日程编辑表单；点战役标记 → 战役详情；「＋添加」→ 日程新建表单（日期预填今天）。
- **课表 → 日程**：课表空白格新建日程时预填日期与节次时间；课程详情卡「＋建日程」预填课程名/时间/教室到备注。
- **日程 ↔ 战役**：日程是原子单位，战役是分组容器（Task.campaignId）。战役窗口的所有操作（完成/改期/删除/批量）直接作用于日程实体；日程列表与首页同步变化。反向：日程条目上的战役标记 → 战役详情。
- **设置 → 全局**：当前学期决定周次计算与课表内容；节假日决定首页徽章、课表遮罩、倒计时 chips；节次时间决定课程起止时刻与提醒时间；提醒提前量决定横幅/通知触发时机。
- **倒计时**：节假日类由 Holiday 自动派生；自定义类独立存储；均在首页倒计时条展示。

## 7. 第一版必须完成的功能

1. 五个页面 + 浮层组件，手机/电脑响应式（断点 768px）。
2. 课表预置录入（5.2 全部数据），周次规则（区间、单双周、按周变教师/节次）正确渲染。
3. 课表日视图默认（手机）、周视图一键切换；周次/学期切换；节假日遮罩。
4. 日程 CRUD + 重复规则 + 分类/优先级 + 筛选搜索 + 完成态。
5. 战役计划：列表、详情窗口、子计划双向跳转、批量操作（含批量新建、批量改期/完成/删除）、现有日程挂载。
6. 首页：今日时间线混排、焦点卡倒计时、待办勾选、快速添加、节假日徽章、倒计时条（预置+自定义）。
7. 提醒：页面打开时横幅 + 浏览器 Notification；提前量可设置。
8. 设置：学期切换、节假日编辑、节次时间编辑、导出/导入 JSON。
9. 云端持久化：刷新/换设备/下次进入数据一致（Qoder Sites 数据库）；部署上线并给出访问链接。
10. 无登录；链接不公开作为隐私手段。

### 首页
6. 首页显示今天日期、星期、正确周次（按 2026-09-07 起算）；时间线按时间升序列出今日课程与今日日程；已过时段条目置灰。
7. 有未开始课程时焦点卡显示课程名、教室、实时递减的倒计时；勾选一个今日待办后进度 n/m 立即更新且刷新页面后保持。
8. 点「＋添加」新建日程后，首页时间线立即出现该条目。
9. 倒计时条至少显示「国庆」「寒假」两个预置 chip，天数正确；可新增自定义倒计时并显示。

### 日程与战役
10. 新建日程填写全字段保存后，在列表对应日期分组出现，分类色 tag、优先级角标、重复图标正确；按重复规则（如每周三）在后续周三的首页时间线自动出现实例。
11. 逾期日程时间文字为红色并出现在「已逾期」筛选中；勾选后移入已完成组。
12. 创建战役「备考四级」，加 3 条子计划（不同日期）；战役卡片显示进度 0/3；完成 1 条子计划后进度变 1/3，且日程列表中该条同步为完成。
13. 从日程列表点某子计划的战役标记 → 进入该战役详情；从战役详情点子计划 → 打开其编辑表单；改期后战役窗口与首页同步更新。
14. 战役窗口多选 2 条子计划批量「移动到某日」，两条日程日期同时改变；批量删除有二次确认。
15. 批量新建一次录入 3 条子计划后，战役进度分母 +3。

### 提醒与持久化
16. 授权通知后，将某日程提醒设为提前 10 分钟并在 10 分钟内到期：页面顶部出现提醒横幅，且收到浏览器通知。
17. 在电脑端添加一条日程，手机浏览器打开同一链接可见该日程（云端同步）；关闭浏览器重开数据不丢失。
18. 设置中导出 JSON 可得包含全部学期/课程/日程/战役数据的文件；清空后导入该文件数据完整恢复。

### 适配
19. 手机宽度（≤768px）：底部 5 Tab 可见；课表默认日视图，顶栏一键切周视图；表单为底部抽屉。电脑宽度：顶部导航；课表默认周视图网格无横向溢出错乱；首页三栏。
