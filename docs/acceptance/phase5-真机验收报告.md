## 已知问题

### 1. adb input tap 坐标映射问题
- **现象**: WebView 渲染的按钮点击失效或误触
- **影响**: 无法可靠测试编辑/删除等 CRUD 操作
- **原因**: uiautomator dump 的 bounds 与 adb tap 实际坐标不一致
- **建议**: 手动测试验证 CRUD 操作

### 2. adb input text 中文支持问题
- **现象**: `adb shell input text "中文"` 抛出 NullPointerException
- **影响**: 无法通过 adb 输入中文文本
- **原因**: Android InputShellCommand 不支持 Unicode 字符
- **建议**: 使用英文文本测试或手动输入

### 3. 主题切换入口未找到
- **现象**: 首页和设置页面均无主题切换按钮
- **影响**: 无法验证多主题功能
- **建议**: 检查代码确认主题切换器位置
